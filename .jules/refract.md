## 2024-05-15 - C# 14 Field-Backed Properties and Collection Expressions
**Observation:** Legacy C# property definitions utilizing manual backing fields (`private _field; public Property { get => _field; set => _field = value; }`) and legacy collection initializations (`new string[0]`, `new List<T>()`) were identified across `Selector.cs`, `ScrollViewer.cs`, `CodeDocument.cs`, `ItemsControl.cs`, `MarkdownParser.cs`, and syntax languages.
**Strategic Action:** Applied C# 14 field-backed properties (`get => field;`) to eliminate boilerplate backing fields in UI controls. Applied C# 12 collection expressions (`[]`) to replace legacy array and list instantiations, reducing lexical verbosity and heap allocations. Fixed a regression in `Selector.cs` selection state transitions by carefully enforcing `try/finally` state management around property mutators. Restored strict API contract in `Slider.cs`'s `OnPropertyChanged` signature.
