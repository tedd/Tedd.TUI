# Changelog

All notable changes to this project will be documented in this file.

## 2026

- **2026-05-31** - Fixed: Focus loss, initial selection coordination, bi-directional navigation syncing, and navigation issues in TextBox, TextEditor, TabControl, and TreeView. Menus and ComboBox dropdowns now correctly auto-close when clicking outside. Fixed Table bottom and side borders not drawing around pagination, pagination click detection, and blank line layout reserving when border is enabled.
- **2026-01-31** - Fixed: Console window resizing no longer corrupts the display or freezes the application. Improved renderer stability and performance during aggressive resizing.
