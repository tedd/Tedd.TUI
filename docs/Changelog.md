# Changelog

All notable changes to this project will be documented in this file.

## 2026

- **2026-07-26** - Fixed: Blazor mouse input — hovering did nothing and dragging selected text instead of driving the control. Bare mouse moves were never forwarded (only moves during a held button were), so `IsMouseOver` never updated: no hover highlights, no hover-revealed affordances, no link hover. The mousedown default action was also left in place, so the browser started its own text selection over the grid and a scrollbar drag smeared a selection instead of moving the thumb. Mouse events additionally dropped keyboard modifiers (breaking Shift/Control click gestures) and sub-cell precision (making scrollbar drags jump a whole cell at a time despite the browser reporting pixels).
- **2026-07-26** - Added: Blazor DOM mode pre-renders the whole of a scrollable region, and prerendered pages now contain the TUI. A scroll viewport becomes an `overflow: hidden` box wrapping the full content, translated by whole cells with a CSS transform — so off-screen rows are present in the document (browser find-in-page and text extraction see all of them), and scrolling moves an already-built subtree instead of forcing a re-render. The whole-cell translate keeps scrolling on exact row boundaries, matching text mode's line-by-line and page steps. Applies to `ScrollViewer`/`Border` and everything built on them (`DialogBox`, `Table`, `TreeView`, `DataGrid`, popups); `ListBox` and `TextEditor` still emit only visible rows. On by default in DOM mode — opt out with `TuiView.PrerenderScrollContent="false"` or `ScrollViewer.SetPrerenderContent(element, false)`, since node count then scales with content extent rather than viewport area. Separately, `TuiView` now renders a frame synchronously during initialization, so statically rendered and prerendered output is no longer an empty container (and interactive WebAssembly no longer shows a blank first paint).
- **2026-07-21** - Added: multi-selection for lists. `Selector` (and therefore `ListBox`) gains `SelectionMode` (`Single`, `Multiple`, `Extended`), a bindable `SelectedItems` collection, `SelectedIndices`, `CurrentIndex`, `SelectAll`/`UnselectAll`, and `SelectionChanged` args carrying `AddedItems`/`RemovedItems`. ListBox implements the standard gestures — click selects, Shift+click extends from the last clicked row, Control+click (or Alt+click) toggles — plus Shift+arrows, Control+A, Space to toggle, and Home/End/PageUp/PageDown navigation. Mouse events now carry `Modifiers` on every host that can report them; the SGR terminal parser previously dropped modified clicks entirely. `ComboBox` stays single-selection, as in WPF.
- **2026-07-19** - Added: SDL2 host (`Tedd.TUI.Platform.Sdl2`). `TuiSdl2Host` opens a native SDL2 window in one call (`Run`) or attaches to an existing SDL2 render loop (`Attach`/`HandleEvent`/`RenderFrame`) — Windows/Linux/macOS, full keyboard/text/mouse input, HiDPI-aware.
- **2026-07-19** - Added: standalone Skia host (`Tedd.TUI.Platform.Skia`). `TuiSkiaHost` renders a TUI onto any SkiaSharp `SKCanvas` or headless to `SKImage`/PNG — no GUI framework needed — with pixel-space mouse and keyboard/text input forwarding.
- **2026-07-16** - Added: DataGrid control with AutoGenerateColumns and high-performance property getters.
- **2026-07-11** - Fixed: Idle 100% CPU spin in the console run loop. `DependencyObject.SetValue` (and the trigger/clear paths) now raise change notifications only when the effective value actually changes, so controls that write dependency properties during Measure/Render (MenuItem, Border, ListBox) no longer re-arm the render loop every frame; an idle app now blocks with zero CPU use. Also fixed: `TuiApp.Stop()` no longer races the run loop (console teardown moved onto the loop thread; `Stop` is thread-safe and idempotent); redirected stdin no longer hot-spins the Windows wait loop; console input mode and mouse tracking are restored on exit; escape sequences split across reads are reassembled instead of leaking garbage keystrokes (SGR mouse reports were also truncated at the CSI introducer and never parsed); Unix synthesizes KeyUp so Space/Enter activates buttons and checkboxes (ClickMode.Release); binding modes are honored (TwoWay/OneWayToSource write back, OneTime transfers once) and `SetBinding` replaces an existing binding instead of leaking its subscription; mouse coordinates account for scroll offsets inside ScrollViewer/Border content; overlays re-fit on window resize (dialogs re-center, popups clamp on-screen); `Table.CurrentPage` clamps when rows are removed; hovering the menu bar no longer steals keyboard focus unless a menu is open; the truecolor renderer re-encodes images only when placements change or text overdraws them, instead of invalidating the whole screen after every frame.
- **2026-05-31** - Fixed: Focus loss, initial selection coordination, bi-directional navigation syncing, and navigation issues in TextBox, TextEditor, TabControl, and TreeView. Menus and ComboBox dropdowns now correctly auto-close when clicking outside. Fixed Table bottom and side borders not drawing around pagination, pagination click detection, and blank line layout reserving when border is enabled.
- **2026-01-31** - Fixed: Console window resizing no longer corrupts the display or freezes the application. Improved renderer stability and performance during aggressive resizing.
